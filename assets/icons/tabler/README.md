# Tabler icon sources

Upstream: https://github.com/tabler/tabler-icons/tree/a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d/icons/outline

Original MIT-licensed file-settings.svg and refresh.svg are retained here. Packaged symbols expand their 2px strokes into path contours for Logitech rendering. Button templates use the same geometry in white, at 60% width and height for compact placement.

Additional original SVGs in this directory use the same pinned upstream revision and MIT license. Window folder uses `app-window`; Split folder uses `layout-columns`. Packaged artwork expands strokes into filled contours without changing the visible outline.
